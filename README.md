Project: Image Enhancement and Quality Detection

This project improves low-quality images by detecting common issues such as noise, blur, and low contrast, then applying enhancement techniques to improve visual quality.

The system follows a step-by-step process:

Input original image
Analyze image quality
Apply enhancement methods
Output improved image
Libraries Used
OpenCV
Scikit-Image
Mahotas
Features
Noise reduction
Image sharpening
Contrast enhancement
Basic image analysis
Output

The project shows a sequence of results:
Original → Processed Steps → Final Enhanced Image

How to Run

Run the main script and provide an input image. The program will display each processing step and the final result.
